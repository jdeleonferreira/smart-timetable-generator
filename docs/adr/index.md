# Decisiones de arquitectura de SmartTimetableGenerator

Aquí están todas las decisiones de arquitectura (ADR) del proyecto.

> Una decisión de arquitectura es una elección de diseño que responde a un requisito funcional o no funcional
> importante para la arquitectura. Un ADR registra una sola decisión; el conjunto de ADR es la bitácora de decisiones.

Un ADR aceptado no se modifica: solo cambia su estado (obsoleto o reemplazado por otro). Así se puede conocer la
historia del proyecto leyendo la bitácora en orden. Mantenerla sirve para:

- Incorporar más rápido a nuevas personas al equipo
- Evitar aceptar o revertir a ciegas una decisión pasada
- Formalizar cómo decide el equipo

Use el menú o la búsqueda para navegar los ADR.
