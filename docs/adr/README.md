# Registros de decisiones de arquitectura (ADR)

Cada archivo de esta carpeta documenta una decisión de arquitectura del proyecto con el formato
[MADR](https://adr.github.io/madr/): contexto, opciones consideradas, decisión y consecuencias.

## Consultar y crear ADR

```bash
npm install -g log4brains   # una sola vez
log4brains preview          # navegar los ADR en el navegador (se recarga al editar)
log4brains adr new          # crear un ADR nuevo
```

También se pueden crear a mano copiando `template.md` con el nombre `AAAAMMDD-titulo.md`.
